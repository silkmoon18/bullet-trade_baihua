# 通用当日执行改造计划

## 目标

在不把服务器绑定到 `good_etf` 的前提下，让每次策略调用明确声明订单类型、
是否追踪剩余目标以及是否重新定价。聚宽策略只保留策略逻辑；服务器负责条件
判断、QMT 下单、回报入账和重启恢复。

## 已确定的边界

- 业务模型使用 `Enum` 与不可变 `dataclass`；只有 TCP/JSON 和 SQLite 边界使用字典。
- JSON 使用显式编解码、`schema_version` 和类型判别字段，不使用 `pickle` 或隐式
  `dataclasses.asdict()`。
- 执行方式由每次调用传入；连接信息和每个策略的 `JQ/QMT_REMOTE` 模式放在私有配置。
- 配置中找不到 `strategy_id` 时默认 `JQ`，禁止静默进入真实下单。
- 调仓目标只在提交当天有效，不自动延续到下一交易日。
- 条件限价以聚宽参考价计算固定边界。买入仅在 QMT 卖一价不高于边界时按边界价
  挂单；卖出仅在 QMT 买一价不低于边界时按边界价挂单。
- 不主动计算交易所价格笼子；券商拒单如实记账，不突破策略价格边界。
- 已处于活动状态的限价单不因同价重复撤挂。只有订单进入终态且仍有剩余目标时，
  才按 `FollowUpPolicy` 决定是否再次提交。
- 行情条件使用 QMT tick 回调；订单、成交、错误和断连使用 QMT trader 回调。
  主动查询只保留启动、重连、回调异常看门狗和收盘对账。

## 执行模型

订单类型：

- `LIMIT`：按参考价或显式限价提交。
- `CONDITIONAL_LIMIT`：行情进入可接受范围后才按指定边界/对手价提交。
- `MARKET`：使用对应市场的 QMT 市价类型。
- `MARKETABLE_LIMIT`：按给定保护范围生成积极限价，不伪装成市价单。

独立策略维度：

- `FollowUpPolicy.NONE`：订单终态后不再为剩余量补单。
- `FollowUpPolicy.UNTIL_FILLED_TODAY`：当日内对终态剩余量继续补单。
- `RepricingPolicy.KEEP_ORIGINAL`：始终沿用原始参考价/边界。
- `RepricingPolicy.RECOMPUTE`：补单时按最新参考价重新计算。
- `ExecutionRequest.sell_style`：可选卖侧覆盖；未设置时买卖都使用`style`。GoodETF借此在同一组合意图中先市价卖出，再条件限价买入。

## 切片

### E01：执行契约与编解码（已完成）

- 新增通用执行 `Enum`、不可变 `dataclass` 和校验。
- 新增显式 `to_wire/from_wire`，覆盖非法字段、未知版本和未知类型。
- 将执行请求和交易日持久化进组合意图，不新增重复业务表。

出口：领域和编解码单测通过，旧数据库和旧调用使用兼容默认值。

### E02：规划器和当日生命周期（已完成）

- `submit_target_weights` 接收 `ExecutionRequest`。
- 根据订单类型计算价格；条件不满足时保持等待且不创建券商订单。
- 活动订单不撤挂；终态剩余目标按追单策略处理。
- 旧日意图失效，不能阻塞新交易日目标。

出口：限价、市价、条件限价、追单和跨日失效单测通过。

### E03：QMT 回调推进（已完成）

- MiniQMT 行情适配器提供内部 tick 监听与按标的订阅。
- QMT broker 把订单、成交、错误和断连回调转为内部事件。
- Strategy API 在事件循环中串行执行条件检查、账实同步和意图推进。
- 启动和重连保留一次主动对账；不增加固定 1 秒订单轮询。

出口：伪 QMT 回调测试证明条件到达才下单、成交回报可推进下一阶段。

### E04：聚宽执行门面和 GoodETF（已完成）

- 私有配置按 `strategy_id` 指定模式，缺失默认 `JQ`。
- helper 暴露执行 dataclass、组合提交和真实组合视图门面。
- `good_etf.py` 删除连接、协议和意图恢复细节，只保留策略参数、选股、权重和风控。
- 普通调仓卖出使用当日追踪市价IOC，买入使用条件边界限价；止损使用当日追踪市价IOC；止盈使用条件边界限价。

出口：切换 `JQ/QMT_REMOTE` 只改私有配置，聚宽导出文件可直接上传。

### E05：审查、测试和部署说明（已完成）

- 更新契约、helper、导出、planner、API 和适配器测试。
- 运行 JoinQuant clean-room 导入、类型契约和相关 server 测试。
- 更新使用说明、配置示例、模拟盘验收和开启真实交易前检查项。

出口：相关测试全绿；真实交易开关仍保持关闭，未经再次确认不做小额实盘。
